HG2Gui — implementation audit
Where the code and the guide disagree

Read against HereLiesAz/HG2Gui@master, tree 251c4ce, 21 Aug 2026. The UI has moved again since the last sync: composeApp/src/commonMain is gone and every screen now lives in shared/src/commonMain/kotlin/…/ui/. PillMenu.kt has grown from a sketch to 58 KB of load-bearing, heavily-commented implementation, and two new files — PillPerimeterReveal.kt and PillWrapReveal.kt — implement the run transition at two levels of fidelity.

The headline: the palette, the timing constants, and the ground rotation are implemented exactly. What is missing or wrong is concentrated in motion — one animation absent entirely, one contradicting the sheet, one wrong in every number — plus two structural problems (a duplicate theme, an unimplemented type scale) that will keep producing drift until they are fixed.

This document is a handoff. Parts one to three are the audit; Part four carries drop-in Kotlin for every defect and Part five the exact guide copy changes, so a session picking this up needs nothing else. Part six is the order to do it in.

Part three b is new, and is the part to read first if the complaint is that an animation works sometimes: seven runtime defects that have nothing to do with the guide, four of which are one-line fixes. The intermittency is the tell — every one of them is state-dependent.

One note on the staged patch

The patch/ directory in this project is now substantially obsolete. AzphaltTokens.kt and GroundRoller.kt duplicate work that already landed upstream inside the Azphalt object in PillMenu.kt — including the weighted ground roll and the two-reroll cap, implemented independently and slightly better than the staged version (process-wide rather than composition-scoped, so a second Activity cannot disagree about the current ground). FilesScreen.kt is also stale: upstream's is now 54 KB against the staged 18 KB. Only SplashScreen.kt and CommandReferenceScreen.kt still have no upstream counterpart. Recommend deleting the rest rather than carrying a diff nobody will apply.
