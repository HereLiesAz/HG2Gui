HG2Gui — surfaces
Seven screens

The menu drives commands; these are what commands open. Each keeps the foundations — capsules, no icons, hue by hash — but takes the layout its own job needs. Three grounds now sort them by kind: gold for system state, magenta-cap for anything you browse, navy for a session doing work. Package manager and the Guide are live — tap a package to install it, tap an argument to build a command and watch it dock as a breadcrumb.

Decisions worth arguing with

Files splits the tap: the body opens, the end-cap chooses — so multi-select needs no long-press and no checkbox. Filenames keep their real case, the only lowercase outside body copy. Processes is the one screen where a capsule's length means something: processor share. A running job is a capsule unfolding — the system's own reveal, slowed to the length of the work, so there is still no spinner.
