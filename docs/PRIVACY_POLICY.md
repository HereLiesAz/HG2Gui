# Privacy Policy

Last updated: 2026-08-04

Thank you for using HG2Gui ("the Project"). This Privacy Policy explains what information the Project may collect, how that information may be used, and the choices you have about the collection and use of your information.

This repository is open-source and maintained by HereLiesAz. If you have questions about this policy or privacy-related requests (data access, deletion, or corrections), please open an issue at https://github.com/HereLiesAz/HG2Gui/issues or contact the maintainer via their GitHub profile.

1. Scope

This policy applies to the HG2Gui project and any official releases distributed from this repository (source code, prebuilt binaries, and documentation). It does not apply to third-party forks or distributions; check those projects' policies separately.

2. No Personal Data Collection by Default

HG2Gui is designed to work locally on your device. By default, the Project does not collect, transmit, or store personal information about you to the Project maintainers or any central service.

3. What Information the Project May Access or Produce Locally

- Device and Environment Information: When run on your device, HG2Gui may read information required for operation (for example, filesystem paths you point it at, OS version, or device model) only insofar as it is necessary to perform its functions.
- Command / Usage Output: Logs, error messages, and command output are produced locally. These are not sent anywhere unless you explicitly share them (for example, pasting into an issue, sending to a third-party, or opting into telemetry).

4. Optional Telemetry or Crash Reporting

If the Project includes an optional telemetry or crash-reporting feature, it will always be explicitly documented and disabled by default. If you enable telemetry, the policy below applies to that data collection:

- What may be collected: anonymous usage metrics (feature usage counts, version number, non-identifying environment details) and crash reports (stack traces, exception messages, minimal environment information).
- Purposes: help the maintainers improve the Project, prioritize bugs, and understand how people use the Project.
- Aggregation and Retention: collected data will be aggregated and retained only as long as needed for maintenance and product improvement, and will not be sold to third parties.
- Opt-out: you can disable telemetry at any time; instructions for disabling telemetry will be included in the documentation or release notes when telemetry is available.

5. Third-party Services and Components

HG2Gui may include or rely on third-party open-source libraries and tools. These components may have their own privacy practices. When included in releases, those components are governed by their respective licenses and policies. You should consult the documentation of any bundled third-party services for specific details.

6. Sharing Data (User Actions)

If you choose to open an issue, create a pull request, or contact maintainers via GitHub and include logs, stack traces, or other debugging information, that information will become part of the public issue or PR and therefore public. Do not paste secrets, credentials, or personal data into issues or PRs.

7. Security

The maintainers take reasonable steps to protect any data they receive (for example, from optional telemetry or user-submitted reports). However, no transmission or storage can be guaranteed to be 100% secure. If you need to share sensitive information with the maintainer, contact them privately via a mutually agreed channel — do not include secrets in issues or PRs.

8. Data Subject Rights (GDPR, CCPA and Similar Laws)

Where applicable, you may have rights under data protection laws (for example: access, correction, deletion, objection, or portability). Because HG2Gui does not collect personal data by default, these requests are unlikely to be applicable. If you believe the Project has collected personal data about you (for example, via optional telemetry you enabled or via information you submitted), please open an issue or contact the maintainer and provide details so they can respond.

9. Children

HG2Gui is not intended for use by children under the age of 13. The Project does not knowingly collect personal information from children.

10. Changes to This Privacy Policy

The maintainers may update this policy from time to time. When changes are made, the "Last updated" date at the top of the file will be updated. Significant changes will be noted in the repository changelog or release notes when practical.

11. How to Contact Us

For questions, requests, or concerns about privacy, please open an issue at:

https://github.com/HereLiesAz/HG2Gui/issues

or visit the maintainer's profile:

https://github.com/HereLiesAz

12. A Note About Distribution

This repository is public. Any code, issues, or pull requests you publish here may be visible to others. When distributing builds or packages derived from this repository, maintainers recommend documenting any additional telemetry or data collection in the distributed package's release notes or bundled documentation.
