# HG2Gui Tangent Pack

Repo-ready assets for the canonical Guide tangent system.

## Structure

- `docs/animation-design-system/guide-tangents.md`
  - Canonical editorial and animation rules for Guide tangents.
- `docs/animation-design-system/tangent-scripts.md`
  - Combined scripts for all current tangents.
- `assets/tangents/cat/`
  - 12 artwork-only frames + script.
- `assets/tangents/elevator-incident/`
  - 12 artwork-only frames + script.
- `assets/tangents/package-manager-incident/`
  - 12 artwork-only frames + script.
- `assets/tangents/cartographical-disaster/`
  - 6 artwork-only frames + script.

## Canonical tangent placement

1. `cat` theology tangent → immediately before canonical `cat` / concatenate.
2. The Elevator Incident → immediately before canonical `mv`.
3. A Small Empire of Dependencies → immediately before canonical `pkg install`.
4. The Cartographical Disaster → immediately before canonical `find`.

The frame files contain animation artwork only. Storyboard chrome, captions, timing labels, titles, borders, and prompt-board UI have been removed.
