What the shell can do that the interface cannot

Read against master, tree 9906587. Almost every gap below traces to one architectural fact: there is no pseudo-terminal between the interface and the shell. Commands run one-shot, output arrives as a finished block, and stdin is simulated by watching for a pause and popping a prompt. That decision bought the whole typographic treatment — you cannot set text beautifully on a page you do not control — and it is why this app looks the way it does. It also draws a hard line around what it can run.

The notable part: terminal-emulator/ and termux-shared/ are both vendored in the repository already, 177 files of working PTY implementation, and nothing in shared/ui/ talks to them. The capability is in the building. The interface has never been introduced to it.

Credit where it is due

Several hard things are already solved and should not be relitigated: interactive prompts are detected and answered inline rather than dropping the user into a raw shell; password prompts mask themselves by inspecting the prompt text; ssh has a purpose-built flow; tabular output is typeset as a real two-column grid instead of monospace; there is no spinner anywhere; and a plain-text editor exists precisely because nano cannot be handed a terminal. The interface has been designed around the constraint intelligently. The question is whether to keep designing around it.

Recommendation Option three, and start with the four smallest items in tier two — exit codes, stderr, streaming, output bounds. Each is a day or two, and together they are the difference between an app that looks composed and one you would trust with a build. Escape parsing and wide-output reflow belong in the same pass and are equally terminal-independent; they are simply larger pieces of work, not later ones. Nothing in tier two commits you to a terminal. Then wire the vendored emulator behind a single full-screen surface for the dozen tools that genuinely need one. The interface stays the interface; the terminal becomes a room you can walk into rather than the house you live in.
