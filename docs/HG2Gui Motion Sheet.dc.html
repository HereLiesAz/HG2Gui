Implementation — Kotlin Compose
The same sixteen, in code

Every specimen above reduces to one of four primitives: a length animation, a hinged rotation, a sequential cascade, and a wipe. Nothing here needs a physics engine or a third-party library — Animatable, graphicsLayer, and a for loop cover all of it. Code below is the reference implementation; it belongs in ui/menu/ alongside PillMenu.kt.

00 — Timing tokens

The menu is linear; the page keeps the house curve. Two easings, four durations — anything else is a bug.

{{ kt.k0 }}
01 — Unfold, row stagger, press to extend

All three are the same animation: interpolate width, never scale and never clip. Scaling distorts the label and the end-caps; clipping shears a rounded tip off. Animating the width keeps both tips on the shape the whole way.

{{ kt.k1 }}
02 — Stack arrives, stack leaves, host drops

The stack travels as one column on one clock — no per-row stagger — so it reads as a physical pile rather than a list animating itself. Only the top pill overshoots, and it corrects after it has landed.

{{ kt.k2 }}
03 — Children cascade (the hinge)

The defining animation. Each child swings a full 360° — not 180° — so it starts and ends face-up while spending the middle of the arc hidden behind the pill it came from. The hinge alternates ends: child 0 pivots on its right tip, child 1 on its left, and so on. Each child's origin is the pill below it, so the whole run reads as one thing unpacking itself. The upward lift is folded into the last 10% of the swing, so both finish on the same frame.

{{ kt.k3 }}
04 — Struggle, break free, fall (and hand-off)

One continuous motion, not four chained animations. The pill stretches slowly to 1.06× as if stuck, snaps in from its left edge down to 0.4×, then flies right at the speed the snap was retracting it — the flight duration is derived from the snap's px/ms rate, which is what makes the release read as elastic rather than scripted. It hits the right edge and jiggles on that tip. Hand-off is the same run, with the last third of the fall swooping back to land as the breadcrumb.

{{ kt.k4 }}
05 — The wobble

Whenever the pills move together, the stack sways: it is a pile, so the higher a pill sits the further it swings, hinged on its visible right end and damping out in three diminishing swings. Never a loop, never a bounce back into motion.

{{ kt.k5 }}
06 — Reading motion: wipe-on and parallax

Text assembles in reading order along one axis and stops dead — no fade, no loop. The background wash drifts on a slower clock than the text over it, which is the whole of the parallax: two clocks, one direction.

{{ kt.k6 }}
What holds across all sixteen

A stack that moves as one sways: it is a pile, and the higher a pill sits the further it swings, damping out in three diminishing swings. The motion is allowed to be funny, and the joke is always timing rather than a wink — a pill that is stuck and straining, one that leaves late and overshoots, a host that lands like it weighs something, a failed command that gets a third of the way round and thinks better of it. Nothing is ever cute about it: no bouncing, no cartoon squash beyond a hair, no character where a plain move would do. Nothing fades: a capsule is revealed by growing in length — both rounded ends belong to the shape, so neither is ever masked off — and text is wiped so the glyphs never stretch. Nothing loops: a thing plays once and settles, and replay is a button. Nothing idles: there is no spinner anywhere, because a running job is the unfold itself, slowed. Motion in the menu is linear — at those speeds an eased pill reads as a fault — while the page keeps the house curve, fast out and long settle. And every change of state is animated end to end: nothing on this sheet appears or vanishes on the spot.
